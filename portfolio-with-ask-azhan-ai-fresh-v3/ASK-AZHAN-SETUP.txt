ASK AZHAN AI — SIMPLE DEPLOYMENT

1. In Netlify, add environment variable GEMINI_API_KEY.
2. Optional: add GEMINI_MODEL. If omitted, the function uses gemini-3.6-flash.
3. Deploy the COMPLETE extracted folder with Netlify CLI from this folder:
   netlify link
   netlify deploy --prod --dir .
4. Test: https://YOUR-SITE.netlify.app/.netlify/functions/ask-azhan
   It should return JSON with ok:true, apiKeyConfigured:true, and the model name.

Never place your API key in JavaScript, HTML, GitHub, or this ZIP.
